# Что делает каждый скрипт

build_excel.py собирает все данные в один файл excel_statistical_functions.xlsx:

Лист «Все функции» — сводная таблица: название, английское название, описание, синтаксис, аргументы, замечания, ссылка на справку и ссылка на лист с примером.
По одному листу на каждую функцию. Там пример-таблица в том же виде, что у Microsoft. Справа добавлена колонка «Результат (Excel)» с настоящей формулой, которую Excel считает сам.

make_screenshots.py открывает этот файл в Excel и сохраняет PNG-скриншот таблицы с каждого листа в папку screenshots/.
## Как запустить 
Установите Python (python.org). Затем в командной строке выполните: pip install requests beautifulsoup4 openpyxl pywin32
Положите оба файла в одну папку и откройте в ней командную строку.
Сначала проверьте на пяти функциях: python build_excel.py --limit 5
Если файл получился нормальным, запустите полностью: python build_excel.py. Это займёт несколько минут.
Скриншоты: python make_screenshots.py. Для них нужны Windows и установленный Excel.

Скачанные страницы сохраняются в папку cache. Если часть страниц не загрузилась, просто запустите скрипт ещё раз.
